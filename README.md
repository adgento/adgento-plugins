# Adgento for Claude

Plugins by [Adgento](https://adgento.app).

## Adgento

A digital marketing agency inside Claude: strategy, SEO, Google and Meta campaigns, content, creative, analytics and PDF reports, in Hebrew or English. 14-day free trial.

**Install:** add the marketplace below, install **adgento**, then connect `https://adgento.app/mcp` in Settings → Connectors and sign in with your email. Guide: https://adgento.app/install/

## Post Studio

Write and design on-brand social posts inside Claude: brief, copy, two designs in your brand, refine, export as PNG.

**Install** (Claude desktop app):
1. Customize → Plugins → Add → **Add marketplace** → `adgento/adgento-plugins`
2. Find **post-studio** and click **Install**
3. Add → Manage marketplaces → ⋯ next to **adgento-plugins** → turn on **Sync automatically**
4. In a new chat, write **install Post Studio**

More: https://adgento.app/post-studio
